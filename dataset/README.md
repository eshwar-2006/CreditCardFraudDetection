# Dataset Instructions

Place the Kaggle credit card fraud dataset into this folder.

1. Download from Kaggle: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Extract the ZIP.
3. Move `creditcard.csv` to this folder.

The application expects the file path:

```
dataset/creditcard.csv
```

Do not commit the dataset file to version control if the repository is shared.
